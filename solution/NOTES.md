# 参考解说明

本题的正确答案由同一套化学规则逐层复算，不依赖预先写死的样品结论。

1. 色谱处理对乙酸乙酯和内标分别使用各自的积分窗口与前后锚点。基线由两个锚点区间的均值连成直线，积分只在窗口内做基线扣除后的梯形累加。
2. 校准使用响应比 `r = a + b*x`，权重是 `1/x^2`。加权均值、加权残差和同一组权重一起用于求斜率、截距、R2、`s_yx`、LOD和LOQ；最低校准点使用更宽的80%至120%回收率窗口。
3. 样品先按校准曲线换算到仪器浓度，再乘各自稀释倍数并扣除方法空白，最后钳位到非负值。平行样用两条样品结果的平均值，RPD按两值均值计算；加标回收率使用扣除空白后的加标结果减去平行样均值。
4. 状态传播先看校准与空白，再看LOQ，最后看该样品的平行样和加标结果。整批只把 `qc_failed` 视为失败，低于LOQ的样品本身不造成整批失败。

随包数据由 `solution/generate_data.py` 使用种子20261022生成。生成器把线性基线、两个高斯峰和固定标准差噪声叠加，生成文件中的时间、进样顺序和任务元数据都没有另外改写。
